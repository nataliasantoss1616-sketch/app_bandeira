# Flag Game

Jogo de perguntas em Flutter para testar o conhecimento de bandeiras de 190 países
de cinco continentes. As bandeiras são exibidas como emojis, sem necessidade de
conexão com a internet ou download de imagens.

## Como jogar

1. Escolha o modo aleatório ou selecione um continente.
2. Defina a duração da partida: 30 segundos, 1, 3 ou 5 minutos.
3. Identifique o país correspondente à bandeira entre quatro opções.
4. Confira seus acertos, respostas e percentual ao final do tempo.

## Executar

Com o Flutter instalado, rode:

```sh
flutter pub get
flutter run
```

Para validar o projeto:

```sh
flutter analyze
flutter test
```
